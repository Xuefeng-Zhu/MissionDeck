# Browser context boundaries

Capture once uses a toolbar/context-menu gesture or existing exact-site access. An open side panel does not grant access to a newly selected tab. Chrome may require clicking the toolbar icon again. The extension asks separately for optional tab metadata and selected exact-origin DOM access. Optional wildcard declarations enable the site picker; they are not installation grants. No history, cookies, debugger, network interception, or incognito capture is enabled.

The tab picker stays local. Up to five sources are selected; unrelated tab metadata never enters server/model context. Discarded pages are not reloaded or activated. Extraction excludes forms, input values, editable drafts, hidden nodes and frames before traversal. It bounds text to 20,000 characters per page and 50,000 per request. Structured tables retain observed cells; unknown rows and inaccessible content are not invented. Internal/restricted pages need manual input; screenshots do not bypass this boundary.

Live Assist has a ten-minute memory-only session and exact site list. Collection runs every three seconds while its panel is mounted, with nonoverlapping requests and hash coalescing. It collects explicitly selected background tabs and the authorized foreground page. Browser restart does not restore consent. Pause, permission loss, expiry, mission switch and panel close clear temporary local context and stop sharing. A site grant may persist until explicitly revoked in Manage Sites. Local extraction consent and automatic model sharing are separate; automatic sharing is off initially.

Automatic sharing sends bounded text to the authenticated local backend and makes it available to the selected conversation model via the existing CopilotKit v2 context. An update does not invoke the model. Each shared request gets a new immutable request ID and sources; context is serialized with the conversation request. Raw temporary backend text expires after ten minutes, is excluded from reads after expiry, and is purged every minute while the server runs (on restart before periodic cleanup). When offline, physical deletion waits for server restart. Minimal replay/revocation metadata contains no source text. Local database files, OS backups, and previously transmitted provider copies are outside an in-memory erase guarantee.

The backend uses the authenticated local user/workspace principal. Client workspace IDs and unnecessary tab/window/document IDs are rejected. This app still uses a fixed local identity, not hosted multi-tenancy. Revocation cannot recall already transmitted data or delete approved workspace artifacts. Explicitly saving a capture as evidence retains it under existing mission retention rules and may invoke the configured planning model; delete the mission only through its existing explicit local deletion control. External workspace artifacts remain intact.

Screenshots require an explicit request, successful page access, and active visible-tab identity checks before/after capture. Preview/redaction/discard are local. Image transmission and vision inference are not implemented; no screenshot is automatically shared by Live Assist.

API documentation was checked September 12, 2026. Automated tests distinguish mocked permission/race contracts from actual unpacked browser coverage; native toolbar/context-menu/side-panel UI needs the [manual demo checks](upgrade-demo.md).

The frozen text payload includes bounded literal table rows and observed header roles, retaining the snapshot/URL citation. Raw tab titles are not substituted for the extractor's redacted title. Screenshot cropping accepts validated pixel bounds and supports keyboard input; images remain local.

Outgoing communications use a separate per-action disclosure review showing the exact recipients, payload and saved source excerpts. This approval does not change provider ACLs or establish a standing policy. Public channels, expanded rosters, group-shared/published calendars and incomplete availability fail closed. No communication or invitation was sent during implementation.
